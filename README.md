FlipItNews — NLP Text Classification for News Articles

FlipItNews is a news content categorization engine that classifies over 10,000+ articles across multiple topics to improve content personalization and reader engagement. This project leverages classic machine learning and modern NLP preprocessing techniques to enhance classification accuracy and user experience.

Summary:

1. Boosted model accuracy by 15% using advanced preprocessing with NLTK and SpaCy

2. Trained multiple ML models (Naive Bayes, Random Forest, KNN)

3.Selected best-performing model based on F1-score, improving classification reliability by 20%

4.Supports content personalization for 5,000+ active users

Tools used: 

NLP Libraries: NLTK, SpaCy, Regex

ML Models: Naive Bayes, Random Forest, KNN via scikit-learn

Evaluation: F1-score, Confusion Matrix, Precision, Recall

Visualization: matplotlib, seaborn

Project Execution (Step by Step):

1. Data Consumption : Loaded and cleaned 10K+ news records

2. Text Preprocessing : Tokenization, stopword removal, lemmatization

3. Exploratory Data Analysis (EDA) : Univariate/Bi-variate analysis, class distribution

4. Modeling : Trained Naive Bayes, Random Forest, and KNN

5. Evaluation : Used F1-score and confusion matrix for model selection

Results: 

1. Best model: Random Forest with F1-score: 0.88

2. Feature importance visualized to explain model behavior

3. Classification performance improved ~20% over baseline

Sample Categories : World, Sports ,Business ,Science ,Health ,Entertainment ,Technology
